# Interface direction

Working title: Corridor. This is a prototype label, not a settled project name.

The map is the primary work surface: detailed, navigable public geography underneath clearly separate synthetic district connections. No agency insignia, classification claims or fictitious operational authority.

Palette: pure black #000000 for the page and main panels; raised black #080808 only where depth is needed; structural gray #292929; text #e5e5e5 and secondary #a3a3a3. Blue #438fff marks documented evidence, yellow #ffd000 marks unknown/experimental signals, and red #ff4545 marks disputed evidence or errors. Brand, navigation, buttons, forms, geographic context and document previews remain monochrome. Color never carries a signal without text or a pattern.

Typography: system sans for reading and navigation, tabular numerals for quantities, compact monospace only for coordinates, zoom and source references. Fine dividers, small corner radii and no decorative gradients or glow.

Layout: navigation | geographic work surface | evidence inspector. The atlas uses conventional mouse-wheel, drag, double-click, keyboard and touch interactions. Search and layer controls sit inside the map without obscuring attribution; dense local details emerge as users zoom.

Review: the explicit black intelligence-workspace brief supersedes the original blue palette. Keep ordinary product actions grayscale so evidence has exclusive use of chromatic signals. Detailed streets are geographic context and never turn an aggregate corridor into a verified street journey. Preserve a visible fallback when online tiles are unavailable.
