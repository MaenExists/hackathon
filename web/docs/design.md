# Interface direction

Working title: Corridor. This is a prototype label, not a settled project name.

The map is the work surface: a Kerala atlas with evidence connections, accompanied by a narrow, readable investigation panel. Geographic boundaries carry the visual identity; no decorative imagery or agency insignia.

Palette: deep ocean #101c2d, panel #172538, land #24394b, mist #e1eaf1, water blue #66b9de, reviewed teal #68d5bb, hypothesis amber #efbd73. Use a light document canvas for exported briefs.

Typography: system sans for the analyst workspace, tabular numerals for quantities. Quiet sentence-case labels, generous map area, restrained dividing lines. A compact navigation rail becomes a horizontal navigation on small screens.

Layout: navigation | flexible geographic canvas | evidence inspector. A timeline lives below the map. Filters and role context stay above it. Alternative workspaces reuse the same shell.

Review: the dense layout follows the analyst workflow rather than a generic statistics dashboard. The map receives the visual emphasis; forecasting, source quality and limitations use plain tables and concise prose. All geographic connections represent aggregate locations, never actual roads.
